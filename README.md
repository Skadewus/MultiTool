 # MultiTool

**A free all-in-one panel for After Effects.** Custom easing curves, anchor point control, quick layer tools, and more, all in one clean panel.

[![Download](https://img.shields.io/badge/Download-Latest%20release-blue)](../../releases/latest)

---

## Features

### Curve Editor
Draw your own easing curves and apply them to selected keyframes in one click.

- **Apply curve** to selected keyframes
- **Quick presets**: Mid, Tight, Out, Tight in, Twin, Tight out, Straight, In, Soft
- **Reset**, **Random**, **Save**, **Copy** and **Paste** curves
- Edit and manage your saved presets

### Anchor Point Adjuster
Move a layer's anchor point to any corner, edge, or the center with a single click.

### Quick Tools
- **Pre-comp** selected layers
- **Center in comp**
- **H flip** and **V flip**

### Add Layer
Create layers instantly: **Null**, **Text**, **Solid**, **Shape**, **Camera**, and **Adjustment** layer.

### More coming
MultiTool is actively developed by  me, and more tools will be added in future updates.

## Installation

MultiTool is distributed as a `.zxp` file.

1. Download the latest `MultiTool.zxp` from the [Releases page](../../releases/latest).
2. Install it with a ZXP installer, such as [ZXPInstaller](https://zxpinstaller.com/) or the aescripts + aeplugins Manager App. Drag the `.zxp` file into the installer window.
3. Restart After Effects.
4. Open the panel from **Window > Extensions > MultiTool**.

---

## Uninstall

You can remove MultiTool with the same ZXP installer you used to install it.
